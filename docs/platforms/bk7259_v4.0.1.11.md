## 已确认

- 芯片：BK7259。
- Armino SMP 维护分支：`release/v4.0.1`。
- 第一阶段参考板：`bk7259_robot`。
- SDK 与 robot solution 使用同名 release tag。
- BK7259 采用 AP + CP 双子系统，目标产物是 `all-app.bin`。
- 项目入口为 `projects/beken_robot/Makefile`，AP/CP 入口分别为 `ap/CMakeLists.txt` 和 `cp/CMakeLists.txt`。
- CP UART0 使用 GPIO10 (RX) 和 GPIO11 (TX)，来源为 `projects/beken_robot/cp/config/bk7259/usr_gpio_cfg.h`。
