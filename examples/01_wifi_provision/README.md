# Example 01: Wi-Fi Provisioning & SNTP/TLS Gate (`bk7259_minimal`)

## Overview
Demonstrates BLE/SoftAP provisioning orchestration (`bk_net`), encrypted Wi-Fi credential persistence (`bk_storage` with `BK_STORAGE_FLAG_SENSITIVE`), and the SNTP/TLS readiness gate on the `bk7259_minimal` profile **with zero dependency on `bk_solution_ai`**.
